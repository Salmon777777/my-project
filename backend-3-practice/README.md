# Backend. Задание 3

Модель SQLAlchemy `Master`, таблица SQLite `masters`: `id`, `name`, `specialization`.
При первом запуске добавляются Анна (Парикмахер) и Мария (Визажист).
Данные читаются из БД, а не из Python-списка:
- `GET /masters` — все мастера.
- `GET /masters?specialization=Парикмахер` — точный фильтр специализации.
- `GET /masters/1` — мастер по ID; неизвестный ID — 404.

Python 3.10+. Из этой папки:
```sh
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
python -m pytest -q
```
Swagger: http://127.0.0.1:8000/docs
База `salon.db` создаётся автоматически рядом с README. Можно задать `DATABASE_URL` на другую SQLite-базу.
Повторный запуск не дублирует начальные данные. БД и сессии закрываются при остановке.
Интеграционный тест на временной БД проверяет все маршруты, фильтр, ошибки, чтение добавленного через SQLAlchemy мастера и сохранность после перезапуска приложения.
Миграция существующей базы не требуется: практика создаёт новую таблицу в новой БД.
