# Задание 2. JavaScript — BORODA

Страница из `frontend-1-practice`, дополненная нативным JavaScript. Без фреймворков, сборки и пакетов.

## Запуск

Откройте `index.html` в браузере двойным кликом или через Live Server. `script.js` подключён в конце `body`.

## Что реализовано

- Сразу выбран день 27 октября 2026 года и показаны его слоты.
- Клик по дню меняет выделение и расписание, сбрасывает выбранное время.
- Клик по свободному слоту обновляет нижнюю панель.
- Стрелки листают месяцы, включая декабрь → январь со сменой года.
- Прошедшие даты, ячейки соседних месяцев и занятые слоты отключены через `disabled`.
- Нижняя панель показывает день недели, число, месяц, год и время.
- «Продолжить» доступно только после выбора времени, выводит итог выбора. Реальная запись не отправляется.
- «Сегодня» возвращает к текущему учебному дню, «Изменить дату» переводит фокус к календарю.
- Воскресенье показывает состояние «всё занято».
- Доступны состояния наведения, клавиатурный фокус, `aria-live` и подписи элементов.

## Данные и структура

«Сегодня» намеренно зафиксировано в `TODAY`: **26 октября 2026 года**. Такой вариант прямо разрешён условиями и сохраняет воспроизводимость проверки. При необходимости измените эту константу. Слоты заданы массивом; доступность 11:00 различается по дням. Воскресенье полностью занято.

`script.js` разделён на данные, состояние, чистые функции, отрисовку/обработчики и инициализацию. После перерисовки обработчики назначаются новым элементам. HTML и CSS основаны на собственной работе BORODA из задания 1; календарь добавлен в том же оформлении.

## Проверка

1. Откройте страницу: выделено 27 октября, список слотов заполнен, «Продолжить» отключено.
2. Выберите 14:00: время появляется в нижней панели.
3. Выберите 28 октября: время сброшено, доступны 11:00 и 14:00.
4. Даты до 26 октября нажать нельзя.
5. Перейдите на ноябрь и выберите 1 число: показано отсутствие окон.
6. Перейдите через декабрь на январь: год меняется на 2027.
7. Вернитесь к доступной дате, выберите время и нажмите «Продолжить».

Шрифт Inter загружается из Google Fonts; при отсутствии сети используется Arial. Данные и логика страницы работают без сети.
