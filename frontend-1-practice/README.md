# Задание 1. HTML/CSS — BORODA

Статическая вёрстка страницы «Выбор даты и времени» по собственному макету барбершопа BORODA. Автор: Курбонов Салмон.

## Макет

- [Экран выбора времени, Figma](https://www.figma.com/design/sSRgSPRU3w1HUvAOW65Sje?node-id=2-8)
- [Прототип записи](https://www.figma.com/proto/sSRgSPRU3w1HUvAOW65Sje?node-id=2-2&starting-point-node-id=2%3A2)
- Размер исходного экрана: 390 × 844 px.

Дата уже выбрана: 27 октября 2026 года. Время 14:00 доступно и выделено, 11:00 и 17:30 заняты. В макете выбор даты расположен на предыдущем экране; на этой странице показаны выбранная дата и кнопка «Изменить дату». Сетка календаря и переключатели месяцев не добавлялись, поскольку их нет на выбранном экране макета.

## Запуск

Откройте `index.html` двойным кликом в браузере или через Live Server. Установка пакетов и сборка не нужны.

Страница использует только HTML и CSS. JavaScript, фреймворков, инлайн-стилей нет. Кнопки статичны: переходы и выбор значений не реализованы, как требуется в задании №1. Наведение и клавиатурный фокус оформлены. Занятые слоты имеют атрибут `disabled`.

Шрифт Inter загружается из Google Fonts; без интернета используется Arial. Изображения этому экрану не нужны. На широком экране мобильный макет расположен по центру, на узком занимает доступную ширину без горизонтальной прокрутки.

## Соответствие заданию

- Семантические `header`, `nav`, `main`, `section`, `footer`.
- Все стили страницы — в `styles.css`.
- Раскладка через Flexbox, без таблиц и `float`.
- Индикатор третьего шага, дата, три слота, изменение даты и нижняя панель.
- Состояния `:hover`, `:focus-visible`, выбранный и занятый слот.
- Подписи для скринридера, `aria-current`, `aria-pressed` и `time`.
