# Задание 3. Основы React — BORODA

Перенос собственной страницы из `frontend-2-practice` на React. Внешний вид и сценарии сохранены. Состояние — в `useState`, интерфейс — JSX, списки — `.map()` с ключами, события — `onClick`. `innerHTML`, ручных DOM-селекторов и `addEventListener` в исходниках нет.

## Запуск

Node.js **22.12+** или **24+** (требование актуального Vite из шаблона курса).

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://localhost:3000). HTML нельзя открывать двойным кликом: JSX обрабатывает Vite.

```sh
npm run lint
npm run build
npm run preview
```

## Структура

- `src/App.jsx` — состояние и обработчики записи, передача пропсов.
- `src/components/BookingHeader.jsx` — шапка и шаги записи.
- `src/components/Calendar.jsx` — дни, выбор даты и навигация по месяцам.
- `src/components/TimeSlots.jsx` — свободные и занятые слоты, результат выбора.
- `src/components/BookingFooter.jsx` — нижняя панель и кнопка продолжения.
- `src/utils/date.js` — чистые функции календаря, сравнения и форматирования дат.
- `src/data/booking.js` — учебное расписание и исходные даты.
- `src/index.css` — оформление BORODA из предыдущей практики.

Каждый компонент — отдельный файл. `useRef` используется только для прокрутки и фокуса календаря; содержимым DOM управляет React.

## Проверка поведения

1. При открытии выбран **27 октября 2026**, показаны слоты, время ещё не выбрано.
2. Выберите **14:00**: нижняя панель обновится, кнопка продолжения станет доступна.
3. Выберите **28 октября**: время сбросится, расписание обновится.
4. Прошедшие даты и занятые слоты отключены.
5. Откройте ноябрь и выберите **1 ноября**: отобразится отсутствие свободных окон.
6. Перейдите через декабрь на январь: год изменится на **2027**. Обратная стрелка вернёт декабрь 2026.
7. «Сегодня» возвращает к учебной дате, «Продолжить» показывает итог выбора.

Как в предыдущем задании, «сегодня» зафиксировано на **26 октября 2026**; это прямо разрешено курсом и делает проверку воспроизводимой. Данные локальные, запись в реальный барбершоп не отправляется.

Использованы зависимости и конфигурация шаблона `tensor-school/learn-web-dev/frontend-3-practice`. Дополнительные библиотеки не добавлялись. Inter загружается из Google Fonts; без сети используется Arial.
