# Backend. Задание 1

Самостоятельное решение двух пунктов практики первой лекции.
`salon.py` содержит справочники мастеров и услуг, класс `Appoinment` (название из задания), список `appointments` и `create_appointment`.
Запись создаётся только при заполненных корректных полях, существующих мастере и услуге и времени от 08:00 до 20:00 включительно.
Одинаковое время у одного мастера повторно занять нельзя; разные мастера могут работать параллельно.
При отказе возвращается `None`, список не меняется.

Python 3.10+, сторонние библиотеки не нужны. В этой папке:
```sh
python salon.py
python -m unittest -v
```
Ожидаемый вывод программы:
```text
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00
```
Перед независимой проверкой неверной записи очистите список: `appointments.clear()`.
В примере курса `len(appointment)` — опечатка: число сохранённых записей проверяется через `len(appointments)`.
Проверены 5 тестов: примеры курса, незаполненные поля, неизвестные ID, формат времени, часы работы и конфликт времени.
